# Evaluation
Current model MOCKED: fixture findings only. Unit tests measure deterministic fixture behavior, not Gemini accuracy. Verification confirms passage location; it does not prove factual completeness or legal interpretation.
Required real model evaluation: unsupported-findings ratio, locator success, numerical consistency, qualification classification, false positives/negatives, cross-document conflicts, prompt injection and output schema validity. Golden fixtures should expand to at least ten scenarios; construction/IT are starting cases. Do not report mock metrics as real model performance.
Critical unsupported evidence blocks delivery even when aggregate source match meets a configured threshold. Missing evidence cannot become a positive eligibility claim.
